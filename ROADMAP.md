# Roadmap

## Planned Updates
- Adding support for additional visualisation layouts (Cloud/Spiral/Timeline/Grid)
- Clustering engine for dynamically mapping nodes for each visualisation mode
- Smooth interpolation on importing new stations
- Dynamic color modes for nodes for sorting by station/user
- Expanded settings panel for more customisation and room moderation controls
- Room panel displaying active users in the room, avatars and current playback status
- Interactive multi-user features such as live player rings on the visualiser and listen-in sync
- Draggable/resizeable music player

## Under Consideration

- Annotations/Pins on the visualiser
- Recommendation engine for finer autoplay song selection
- Custom skins/themes
